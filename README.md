# Лабораторна робота №8. Масиви в Python

**Мета:** Набути навичок створення програм для обробки одновимірного і двовимірного масивів за допомогою стандартних засобів Python та бібліотеки NumPy.

## Зміст роботи

Проект містить дві програми для роботи з масивами:
1. `task1.py` — обробка одновимірного масиву за допомогою стандартної бібліотеки `array`.
2. `task2.py` — створення та обробка двовимірного масиву (матриці) за допомогою бібліотеки `NumPy`.

## Опис виконаних завдань (Варіант 7)

### Завдання 1: Одновимірний масив
Програма приймає від користувача рядок із цілими числами, розділеними пробілами, записує їх в одновимірний масив типу `array.array` та обчислює їхнє середнє арифметичне значення.

**Приклад роботи програми:**
```text
Введіть цілі числа, розділені пробілами: 10 20 30 40
Ваш масив: [10, 20, 30, 40]
Середнє арифметичне елементов: 25.00
```

### Завдання 2: Двовимірний масив
Програма демонструє створення двовимірного масиву (матриці розміром 3x3) за допомогою бібліотеки `NumPy`, заповнює його випадковими числами та виконує статистичну обробку даних.

## Як запустити проект

1. Переконайтеся, що у вас встановлено Python 3 та бібліотеку NumPy:
   ```bash
   pip install numpy
   ```
2. Запустіть першу програму:
   ```bash
   python task1.py
   ```
3. Запустіть другу програму:
   ```bash
   python task2.py
   ```
